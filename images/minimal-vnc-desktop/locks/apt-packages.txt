# Fonts. Chromium runs behind Fortress's own fontconfig, which reads ONLY the
# curated font dirs we hand it — never /usr/share/fonts — so system font packs
# neither render in the browser nor appear in its font fingerprint. We therefore
# ship the bare minimum:
#   fonts-dejavu-core  satisfies fontconfig-config's font dependency (its alt-dep
#                      list is dejavu|liberation|croscore|freefont|…; Noto is NOT
#                      in it). ~2.5MB, never reaches Chromium.
#   fonts-noto-core }  build-time COPY SOURCE only: the Dockerfile curates the
#   fonts-noto-cjk  }  needed script faces into /usr/local/share/fonts-intl
#                      (renamed to their Windows font names) and then PURGES both
#                      packages, so they add no runtime weight.
# Everything else (dejavu-extra, freefont, liberation, indic, khmeros, tibetan,
# nanum, ipafont, wqy-zenhei, thai-tlwg, ubuntu, roboto, unifont, color-emoji,
# …) was dead weight — Chromium never saw it — and is removed. Emoji is covered
# by Fortress's own colour SegoeUIEmoji.ttf (CBDT/CBLC).
fonts-dejavu-core=2.37-2build1
fonts-noto-cjk=1:20220127+repack1-1
fonts-noto-core=20201225-1build1
